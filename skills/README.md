# skills

Packaged pi skills for npi live here (one folder per skill with a `SKILL.md`). npi currently ships none: the
workflows it needs are prompt templates in `../prompts` (`/hypothesis`, `/ablate`, `/prd`, `/preflight`, `/repro`)
backed by the `experiment`, `ledger` and `delegate` tools. Add a skill here only when a workflow needs bundled
scripts or reference files that a prompt template cannot carry.
